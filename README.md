# 눈 내리는 밤, 나는 여동생의 옷을 벗긴다. 한글패치

일본어 Windows PC판 《雪の夜、俺は妹を裸にする。》에 한국어 본문, 선택지, 시스템 메뉴와 이미지를 적용하는 패치입니다.

**[최신 한글패치와 설치 안내](https://github.com/adios1579-lgtm/Yuki-no-Yoru-Korean-Patch/releases/latest)**

### 설치

1. 일본어 원판을 설치하고 게임을 종료합니다.
2. 최신 릴리스에서 한글패치 ZIP을 받아 압축을 풉니다.
3. `눈 내리는 밤 한글패치.exe`를 열고 `SiglusEngine.exe`가 있는 게임 폴더를 선택합니다.
4. **한글패치 설치**를 누른 뒤 **게임 실행**을 누릅니다.

한국어 Windows에서 로캘 에뮬레이터 없이 실행할 수 있습니다. 첫 실행 시 원판 디스크가 필요할 수 있습니다.
